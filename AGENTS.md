# Project Instructions

## Project
This repository contains a PC game prototype built with Three.js and JavaScript.

## Working guidelines
- Keep the game playable in a desktop browser.
- Use the existing project structure and coding style.
- Keep gameplay controls documented in the README.
- Prefer small, focused changes.
- Do not add dependencies unless they are needed for the requested feature.
- Do not commit secrets, credentials, or local machine files.

## Before finishing
- Summarize the files changed.
- Mention any checks you ran and their results.
